# Reproducibility

Every number in [BENCHMARKS.md](BENCHMARKS.md) and every artefact loaded
by the API must be regenerable from the frozen dataset by running
`scripts/regenerate_all_numbers.sh` on a machine matching
`environment.lock`. This file is the enablement companion to
[METHODS.md](METHODS.md) and [CLAIMS.md](CLAIMS.md).

---

## Frozen inputs

- **Dataset**: `dataset_final_resplit/` (1024 train / 368 val / 201 test),
  image-level random split at seed 42. Provenance in
  `dataset_final_resplit/split_info.json`. **Known defect**: video groups
  (`pseudo_<group>__<frame>`) cross splits — all 49 test groups also appear
  in train. Results from this split are optimistic; a group-level re-split
  is required before any external claim.
- **Per-image manifest**: `MANIFEST.md` — SHA256 of every image in every
  split. Regenerated by `scripts/generate_manifest.py`.
- **Weights**: `production_models/yolo_best.pt`, `rfdetr_best.pth`.
- **Calibration + conformal artefacts**: `production_models/{calibration_yolo,
  calibration_rfdetr, isotonic_fusion, selective_thresholds,
  conformal_qhat, conformal_crc}.{pkl|json}`. Regenerated by
  `scripts/fit_calibration.py` + `scripts/fit_conformal.py`.

## Environment

- OS: Windows 11 (developer), Linux Docker (CI) — see `Dockerfile`.
- Python 3.12.
- CUDA 12.x + `torch>=2.2.0` (auto-detected; falls back to CPU).
- Lock: `environment.lock` = `uv pip freeze` output. Regenerate on each
  dependency bump.
- Determinism:
  - `numpy` seed 42
  - `random` seed 42
  - `torch.manual_seed(42)` + `torch.cuda.manual_seed_all(42)`
  - `torch.backends.cudnn.deterministic = True`, `benchmark = False`
  - `PYTHONHASHSEED=42`

## One-shot regeneration

```bash
bash scripts/regenerate_all_numbers.sh
```

Sequence executed:

1. `pytest tests/ -q` — 16 unit tests pass.
2. `python scripts/generate_manifest.py` — refreshes `MANIFEST.md`.
3. `python scripts/comprehensive_evaluation.py --split test` — writes
   `runs/final_eval/comprehensive_evaluation.json`.
4. `python scripts/tune_shadow_threshold.py --split val` — writes
   `runs/final_eval/shadow_threshold_tuning.json`.
5. `python scripts/fit_calibration.py --split val` — writes
   `runs/final_eval/calibration.json` + `production_models/calibration_*.pkl`
   + `production_models/isotonic_fusion.pkl`.
6. `python scripts/fit_conformal.py --calibration-split val --test-split test
    --alpha 0.05` — writes `runs/final_eval/conformal.json` +
   `production_models/conformal_qhat.json` + `conformal_crc.json`.
7. `python -m nbclient docs/notebook_runner.py` — executes
   `05_calibration_analysis.ipynb`, `06_conformal_validation.ipynb`,
   `07_ablation_grid.ipynb` in place.
8. `python scripts/render_benchmarks.py` — pastes the numbers into
   `docs/BENCHMARKS.md`.

Expected wall-clock: ~15 min on RTX 4060, ~2 h on CPU-only.

## Failure modes + recovery

- **Missing weights**: `production_models/*` absent → smoke tests skip,
  API health reports `yolo_loaded=false` / `rfdetr_loaded=false`.
- **Missing calibration artefacts**: `/api/predict` still works but
  `calibrated_confidence` fields are `null`.
- **Missing conformal artefacts**: `conformal_bbox` fields are `null`.
- **Optuna DB corruption**: `optuna.copy_study` to a fresh DB, then
  re-attach.
- **Orphan RUNNING trials**: `UPDATE trials SET state='FAIL' WHERE
  state='RUNNING'`. See Phase 0 cleanup log.
